Native vacuum icon (Matter)

Apple Home only shows a real vacuum tile via Matter (same as Roborock). If you still see a Fan, Matter is not enabled on the bridge running this plugin.

  1. Plugins → TerraMow V600 → enable Child Bridge
  2. Open that child bridge settings → enable Matter
  3. Set Presentation mode to Native vacuum (Matter) and Save
  4. Restart Homebridge
  5. In Apple Home: delete any old TerraMow Fan accessory
  6. In Homebridge logs find Commissioning codes for <mower>
  7. Add Accessory → enter that Manual Code (not the child-bridge Matter code)

A “PASE” / pairing error usually means the wrong code was used, or phone and Homebridge are not on the same LAN with working mDNS/IPv6. Remove any half-added accessory, restart Homebridge, and pair again.

TerraMow MQTT setup

In the TerraMow app, enable Home Assistant integration. That starts the mower’s local MQTT broker and shows the password. MQTT username is always terramow.
